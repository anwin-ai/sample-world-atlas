# World Atlas (ANWIN sample project)

World Atlas is a small Java web application for browsing countries, their states or provinces, capitals and population.

It is the sample project every ANWIN workspace starts with, so you can explore ANWIN's features on real code straight away: follow a request from a web page to the database, see what a change would affect, and review security and compliance findings.

## This application is deliberately insecure

World Atlas contains intentional security flaws and compliance violations so that ANWIN has real issues to find and explain. Never deploy it, never expose it to a network, and never reuse its code.

All credentials, keys and card numbers in this repository are fake. The card number is a standard public test number.

Population figures are rounded approximations for demonstration only.

## Built with

- Java 17, Gradle, Jakarta Servlets and JSP
- JDBC with an in-memory H2 database
